How it works

ETH budget = gas limit × maximum fee in gwei × transaction count ÷ 1,000,000,000. The extra budget is added afterwards.

Actual execution can cost less. This is not a live quote and does not include transferred ETH, exchange withdrawal fees, token amounts, or special L2 fees. Token approvals and purchases can be separate transactions with different gas limits. Calculate them separately when their limits differ. Never enter a private key.
